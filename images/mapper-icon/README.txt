The program icons in this folder (Mapper-*.png, Mapper.ico, Mapper.icns) show the FOOM logo.
They are written by images/foom-logo/make_logo.py; change the script and run it again,
do not edit the files by hand. The file names are kept from upstream so that the build
files need no change.
